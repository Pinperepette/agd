# AGD benchmarks

Generated by `cargo run --release --bin agd-bench`. Profile: `release` (`lto = "thin"`, `codegen-units = 1`). Times are *median over 5 hot iterations*. Smaller is better.

Reproduce: `cargo run --release --bin agd-bench`. The synthetic corpus generator (`agd::corpus`) is fully deterministic given a `(size, seed)` pair, so the inputs are identical across machines.

---

**Reading these numbers.** AGD is *slower in tokens* than Markdown but *faster and more deterministic at every other axis we measured*. The interesting comparison is rarely the raw count — it's whether the format gives the parser something solid to grip. Round-trip stability, byte-stable canonicalisation, and O(1) random access via `[#id]` are the load-bearing claims; this report measures all three.
